===========================================================================================================================================
  Introduction:
===========================================================================================================================================

      This guide provides data-driven recommendations for allocating armor, DPS, and stats when creating custom weapons and
  equipment in AzerothCore. Items created using these recommendations will align closely with existing Blizzard itemization
  patterns, producing balanced, mid-grade (BlizzLike) results.

      This guide complements "A Developers Handbook to Stat Budgeting Custom Items in AzerothCore v1.0". The Developers Handbook
  defines how to calculate an item’s stat budget. This guide recommends how that budget is typically distributed across DPS,
  armor, and stats. While some absolute values are provided here, they are not a substitute for budget calculations.

      This guide is intended primarily for developers new to custom item creation. Experienced modders may also use it as a
  reference when designing ordinary or baseline items. It is not intended for special, experimental, or balance-altering items.



  This guide covers the following topics:

   - 1. Selecting an appropriate Quality and ItemLevel based on player level.
   - 2. Selecting appropriate DPS values based on ItemLevel (dmg_min1, dmg_max1, and delay).
   - 3. Selecting appropriate armor values based on ItemLevel and Armor Type.
   - 4. Selecting an appropriate number of stats based on Quality and ItemLevel.
   - 5. Selecting an appropriate distribution of stat values.

  Each topic is independent and may be referenced as needed.



===========================================================================================================================================
  Slot Group Reference:
===========================================================================================================================================

      Slot Groups are a classification used throughout this document to group items with similar gameplay roles
  and budget behavior. They are derived from observed itemization patterns in AzerothCore and are not arbitrary categories.

  There are twelve Slot Groups: six weapon groups and six equipment groups. Slot Groups are independent of ItemLevel and Quality.



  Weapon Slot Groups:

    1H Weapon
      One-handed melee weapons.
      Includes: 1H Axe, 1H Mace, 1H Sword, Dagger, Fist Weapon

    2H Weapon
      Two-handed melee weapons, excluding staves.
      Includes: 2H Axe, 2H Mace, 2H Sword, Polearm

    Staff Weapon
      Two-handed caster weapons.
      Includes: Staff

    Ranged Weapon
      Ranged physical weapons.
      Includes: Bow, Crossbow, Gun

    Thrown Weapon
      Thrown weapons.
      Includes: Thrown Weapon

    Wand Weapon
      Ranged caster weapons.
      Includes: Wand



  Equipment Slot Groups:

    Major Armor
      High-impact armor slots.
      Includes: Chest, Legs, Robe

    Moderate Armor
      Medium-impact armor slots.
      Includes: Head, Shoulder

    Minor Armor
      Low-impact armor slots.
      Includes: Feet, Hands, Waist, Wrists

    Accessory
      Non-armor equipment slots.
      Includes: Finger, Neck, Off-Hand Equipment

    Shield
      Shield items.
      Includes: Shield

    Back
      Cloak slot.
      Includes: Back (Cloak)

  2. Selecting appropriate DPS values based on ItemLevel (dmg_min1, dmg_max1, and delay).
===========================================================================================================================================

      Weapon DPS should be calculated and accounted for before allocating any other stats. Depending on Slot Group and
  Handedness (InventoryType), DPS may consume anywhere from approximately 9% to 100% of an item’s Final Budget.
  Poor and Common weapons must allocate 100% of their Final Budget to DPS.

      The tables below define the observed average dmg_min1, dmg_max1, and delay values for weapons by ItemLevel.
  Each table represents a single Slot Group and InventoryType, where applicable. DPS values have been
  pre-calculated for convenience.

      Each table also includes the ratio of DPS cost to the Expected Final Budget. This ratio may be used to derive
  appropriate DPS values for ItemLevels not explicitly shown.

  The DPS formula:

    DPS = (dmg_min1+dmg_max1)/2/(delay/1000)

===========================================================================================================================================
  3. Selecting appropriate armor values based on ItemLevel and Armor Type.
===========================================================================================================================================

      Equipment armor should be calculated and accounted for before allocating any other stats. Depending on Slot Group and
  Armor Type (subclass), armor may consume anywhere from approximately 15% to 100% of an item’s Final Budget.
  Poor and Common equipment must allocate 100% of their Final Budget to armor.

      The tables below define the observed average armor values for equipment by ItemLevel. Each table represents a single
  Armor Type (subclass) and Slot Group, where applicable.  Armor Cost values have been pre-calculated for convenience.

      Each table also includes the ratio of Armor Cost to the Expected Final Budget. This ratio may be used to derive
  appropriate armor values for ItemLevels not explicitly shown.



  Accessory has no armor table - Accessory items may include armor values; however, this is uncommon and reflects specific
                                 gameplay roles rather than a general itemization rule.

  Additional Information:
===========================================================================================================================================

      This document provides developers recommended baselines for armor, DPS, and stat distribution. Items created following this guide
  will conform to the power level and structure of existing mid-grade Blizzard items. Legendary, balance breaking and other special items
  are not covered by the recommendations in this guide.

  Before applying the information from this document, developers must first calculate an item's stat budget.
  The required documents are listed below.



  Developers Handbook
    "A Developers Handbook to Stat Budgeting Custom Items in AzerothCore. v1.0"
    <URL of DEVELOPER_DOCUMENT>

    Provides the workflow and tables required for calculating stat budgets. This document utilizes interpolation or derived values.
    This document not only defines what exists in AzerothCore, but what can exist. It is designed for daily use by developers.



  Validation Reference
    "A Derivation and Validation of Stat Budgeting in AzerothCore. v1.0"
    <URL of RESEARCH_DOCUMENT>

    Documents the data sources, analysis methods, and validation steps used to derive the values presented in this document.



  Precision Reference
    "A Verification Guide to Stat Budgeting in AzerothCore. v1.0"
    <URL of PRECISION_DOCUMENT>

    Provides the same workflow and tables as the Developers Handbook using observed 3.3.5 values only, without interpolation or
    derived values. This document is intended for reference and verification. It is not optimized for day-to-day item creation.



  Used as intended, these recommendations produce consistent, BlizzLike items without requiring bespoke tuning.
